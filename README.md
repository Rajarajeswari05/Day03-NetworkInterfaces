## 1. What is a Network Interface Card?

A Network Interface Card (NIC) is a hardware component that allows a computer or other device to connect to a network. It can provide either a wired Ethernet connection or a wireless connection.

## 2. What is Ethernet?

Ethernet is a networking technology used to connect devices over a wired Local Area Network (LAN). It uses Ethernet cables and network interfaces to transfer data between devices.

## 3. What is RJ-45?

RJ-45 is the commonly used connector for Ethernet network cables. It has eight pins and is normally used with twisted-pair Ethernet cables.

## 4. What does UTP stand for?

UTP stands for **Unshielded Twisted Pair**. It is a type of copper cable containing pairs of twisted wires used for network communication.

## 5. Three Common Ethernet Cable Categories

Three common Ethernet cable categories are:

- Cat5e
- Cat6
- Cat6a

## 6. What is a Straight-Through Cable?

A straight-through cable has the same wiring standard at both ends. It is commonly used to connect different types of network devices, such as a computer to a switch.

## 7. What is a Crossover Cable?

A crossover cable has different transmit and receive wire arrangements at its two ends. It was traditionally used to connect similar devices directly, such as two computers.

## 8. What is Auto MDI-X?

Auto MDI-X is a feature that automatically detects the transmit and receive configuration of an Ethernet connection. It allows devices to work without manually selecting a straight-through or crossover cable.

## 9. Difference Between Copper and Fiber-Optic Networking

Copper networking uses electrical signals through copper wires to transmit data. Fiber-optic networking uses light signals through optical fiber.

Copper cables are generally easier and less expensive to install, while fiber can support higher bandwidth, longer distances, and is not affected by electromagnetic interference.

## 10. What is Multimode Fiber?

Multimode fiber is an optical fiber that allows multiple light paths or modes to travel through the fiber. It is generally used for shorter-distance network connections.

## 11. What is Single-Mode Fiber?

Single-mode fiber allows light to travel mainly through one mode. It is designed for longer-distance communication and is commonly used in telecommunications and large network infrastructures.

## 12. Two Advantages of Fiber-Optic Networking

Two advantages of fiber-optic networking are:

1. It supports high-speed and high-bandwidth communication.
2. It is resistant to electromagnetic interference.

## 13. Why are Network Interfaces Important for Cybersecurity?

Understanding network interfaces is important in cybersecurity because security professionals need to know how devices connect to networks and communicate with other systems. Network interfaces are also important when monitoring traffic, performing network analysis, troubleshooting connectivity, and identifying unauthorized network connections.
